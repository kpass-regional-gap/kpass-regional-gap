# kpass-regional-gap

전국 229개 지자체가 모두 참여한 뒤에도 남아 있는 K-패스 이용 경험률의 지역 격차는 어떤 지역 특성으로 설명되는가?

1. 지역 간 이용 경험률 차이를 만드는 요인을 그룹별로 분석한다.
2. 각 지역의 주된 장벽을 찾아 유형으로 구분한다.
3. 유형별 대안을 제시하고, 정부가 검토 중인 개편안과 비교한다.

## 실행 방법

Python 3.11 환경에서 저장소 루트를 작업 디렉터리로 지정하고 아래 명령을 순서대로 실행한다.

```bash
python -m pip install -r requirements.txt
python src/01_build_dataset.py
python src/02_correlation.py
python src/03_pca.py
python src/04_regression.py
python src/05_robustness.py
python src/06_typology.py
```

각 스크립트는 프로젝트 루트 기준 경로를 사용하고 출력 폴더를 자동 생성한다. 02~06은 앞 단계의 출력이 필요하다. 결측값·비정상 수치·중복 시도·17개 시도 누락은 오류로 처리하며 값을 채우지 않는다. 검증을 활성화하기 위해 `python -O` 옵션을 사용하지 않는다. 산점도에는 맑은 고딕, AppleGothic, NanumGothic, Noto Sans CJK KR 중 설치된 글꼴을 사용한다.

## 변수 정의 시 주의사항

**성인대중교통이용률**은 월요일의 유형별 비중이 다른 요일에도 비슷하고, 일반+고령자가 성인에 대응한다고 보는 근사치다. 주간평균이용인원에 월요일 일반·고령자 비중의 합을 곱한 후 18세 이상 인구로 나눈다. 고유 이용자 기반의 실제 이용률을 뜻하지 않으며 중간지표로만 해석한다. 이 지표와 월요일 유형별 비율은 0~1 단위의 비율(백분율 변환 없음), 고령인구비율·미경험률은 %, 비용은 만원 단위다.

2024년 설명변수와 2026년 이용경험률을 결합한 지역 단위 탐색 분석으로, 인과효과를 추정하지 않는다.

**원자료 불일치**: 유형별 이용인원 합계와 월요일 총이용인원이 16개 시도에서 다르다(유형별 합계−월요일 총계: −1~861명, 강원 861명). 원자료를 보정하지 않고 지정된 계산식대로 유형별 합계를 분모로 사용한다. 01 실행 시 경고와 검증표를 남긴다.

## PCA·지수 정의

PCA 적재값은 변수와 주성분 점수의 상관계수로 정의하고, 고유벡터계수도 별도 열로 저장한다. 설명분산비율은 각 주성분의 변수 행에 반복 기록된다. 전체 4변수 PCA는 요인 검증용으로 유지한다.

| 지수 | 정의 |
| --- | --- |
| 인프라지수 | 주간평균배차간격의 z점수 |
| 차량의존지수 | 자가용등록대수와 주행거리의 z점수 평균 |
| 고령화지수 | 고령인구비율의 z점수 |

차량 두 변수의 상관이 양수이면 부호를 맞춘 PC1은 z평균의 √2배여서 순위가 같다. 음수·0이면 동일 순위는 보장되지 않으며, 이 경우에도 지수는 z평균을 그대로 사용한다.

## 회귀 모형

| 모형 | 구성 |
| --- | --- |
| 모형1 | 인프라지수 + 차량의존지수 + 고령화지수 |
| 모형2 | 모형1 + 성인대중교통이용률(z) |
| 모형3 | 모형1 + 월평균대중교통비(z) |

표본이 17개뿐이므로 절편 제외 설명변수는 4개 이하로 제한한다. 모형2·3은 변수 4개로 제한선에 도달하므로 해석에 더 유의할 것.

## 05 강건성 검증 조건

전체 17개, 수도권 제외 14개, 서울 제외 16개, 평일 배차간격으로 교체 17개, 기준 모형의 최대 절댓값 잔차 지역 제외 16개의 5개 조건을 비교한다. 마지막 조건은 다른 제외 조건에 누적하지 않고 전체 17개에서 해당 1곳만 제외한다. 지수 정의는 유지하며, 표준화계수는 각 분석 표본의 X·Y 표준편차로 계산한다. 유의성은 양측 OLS p<0.05이며 표에 p값으로 기록한다. 01에는 이미 평일평균배차간격이 있어 01·02 코드는 변경하지 않는다.

## 06 지역 유형화 규칙

05 기준 모형에서 p<0.05인 요인만 판정에 사용한다. 현재 데이터로 재적합해 05 결과와 일치하는지도 검증한다. 모든 요인의 z와 선택 여부를 저장하며, 비유의 요인은 판정에서 제외한다.

지수별 비교 단위를 맞추기 위해 17개 지역의 각 지수를 다시 z표준화한다(차량의존지수 원값은 z평균이므로 표준편차가 1이 아니다). 인프라·차량이 모두 유의하면 이 두 z의 평균인 구조요인z평균으로 결합하고, 고령화도 유의할 때만 다른 축으로 사용한다. 구조요인z평균은 추가로 재표준화하지 않는다.

| 조건 | 판정 |
| --- | --- |
| 모든 선택 축이 0 이하 | 양호형 |
| 양수 축이 하나뿐 | 해당 요인형 |
| 양수 축이 여럿, 상위 두 값의 차이가 0.5 이상 | 우세 요인형 |
| 양수 축이 여럿, 상위 두 값의 차이가 0.5 미만 | 복합취약형 |
| 유의 요인이 하나뿐(0 기준) | 양호형 / 해당 요인형 |
| 유의 요인이 하나도 없음 | 판정유보 |

높은 z를 취약 방향으로 보는 규칙을 사용하며, 계수의 부호에 따라 축을 반전하지 않는다.

두 유의 축이 있으면 표준화계수 절댓값이 큰 순서로 산점도의 축을 배치한다(구조축 영향도는 두 계수 절댓값의 평균). 단일 축이면 가로축만 분석 요인이고 세로축은 라벨 겹침을 피하는 지역 표시 위치이며, 이때 수평선은 두 번째 요인의 사분면 경계를 뜻하지 않는다. 이 분류는 작은 표본에서 선택한 요인을 이용한 탐색적 상대 분류이며 확정적 지역 진단이 아니다.

## 실행 검증 결과

고정된 패키지 버전과 Python 3.12.7 환경에서 수정·신규 03~06 모두 종료 코드 0으로 완료했다. Python 3.11 직접 실행은 미검증이다.

- 지수 데이터는 17행·20열이며 결측이 없다.
- 차량 두 변수 상관은 0.539057, PCA와 z평균 순위는 일치했다.
- 모형1~3의 R²는 각각 0.7935, 0.8271, 0.8041이다.
- 강건성 5조건의 R²는 순서대로 0.7935, 0.8431, 0.7958, 0.7973, 0.8376이며, 최대 절댓값 잔차 지역은 경기도다. 모든 조건에서 기준 대비 부호·유의성 변화가 없었다.
- 기준 모형에서는 인프라지수만 유의하여 양호형 10개, 인프라취약형 7개로 분류됐다.
- 표본 17개로 인해 OLS 요약의 첨도 기반 정규성 검정은 n<20 경고가 발생한다.
