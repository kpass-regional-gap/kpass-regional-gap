# kpass-regional-gap

전국 229개 지자체가 모두 참여한 뒤에도 남아 있는 K-패스 이용 경험률의 지역 격차는 어떤 지역 특성으로 설명되는가?

1. 지역 간 이용 경험률 차이를 만드는 요인을 그룹별로 분석한다.
2. 각 지역의 주된 장벽을 찾아 유형으로 구분한다.
3. 유형별 대안을 제시하고, 정부가 검토 중인 개편안과 비교한다.

## 실행 방법

Python 3.11 환경에서 저장소 루트를 작업 디렉터리로 지정하고 아래 명령을 순서대로 실행한다.

```bash
python -m pip install -r requirements.txt
python src/01_build_dataset.py
python src/02_correlation.py
python src/03_pca.py
python src/04_regression.py
python src/05_robustness.py
python src/06_typology.py
```

각 스크립트는 프로젝트 루트 기준 경로를 사용하고 출력 폴더를 자동 생성한다. 02~06은 앞 단계의 출력이 필요하다. 결측값·비정상 수치·중복 시도·17개 시도 누락은 오류로 처리하며 값을 채우지 않는다. 검증을 활성화하기 위해 `python -O` 옵션을 사용하지 않는다. 산점도에는 맑은 고딕, AppleGothic, NanumGothic, Noto Sans CJK KR 중 설치된 글꼴을 사용한다.

## 입력·출력 파일

- **입력**: `data/raw/시도별_통합데이터_2024.xlsx`의 `통합데이터` 시트와 `data/raw/dependent_variable.csv`. `비용계산근거` 시트는 사용하지 않는다. 기존 최상위 엑셀은 유지했고 `data/raw/`에 바이트 단위로 동일한 사본을 뒀다.
- **01 출력**: `data/processed/analysis_dataset.csv`(17행, 시도명 포함 17열), `output/tables/monday_total_check.csv`.
- **02 출력**: `output/tables/correlation_results.csv`, `correlation_matrix.csv`, `output/figures/nonexperience_vs_headway.png`. 성인대중교통이용률에는 `중간지표(종속변수아님)`을 표시한다. 유의여부는 보정하지 않은 두 p값이 모두 0.05 미만인지로 판단한다.
- **03 출력**: `output/tables/pca_loadings_all.csv`(4변수 탐색용), `pca_loadings_composite.csv`(3변수 종합지수 가중치·적재값·설명분산), `pca_index_comparison.csv`(3변수 PCA와 z평균의 참고 비교), `output/processed/analysis_dataset_with_indices.csv`(17행, 19열; 인프라차량종합지수·참고용 고령화지수). 지수 파일은 `output/processed/`에 저장한다.
- **04 출력**: `output/tables/regression_모형1.txt` ~ `regression_모형3.txt`, `regression_coefficients.csv`. OLS 요약, X·Y를 모두 표준화한 계수, 절편 포함 VIF를 저장하고 절댓값 잔차 상위 3개 지역을 출력한다. 계수 CSV에는 충분한 정밀도의 p-value를 기록한다.
- **05 출력**: `output/tables/robustness_check.csv`, `pca_loadings_weekday.csv`(평일 기준으로 다시 적합한 PCA).
- **06 출력**: `output/tables/region_typology.csv`, `output/figures/typology_scatter.png`.

## 변수 정의 시 주의사항

**성인대중교통이용률**은 월요일의 유형별 비중이 다른 요일에도 비슷하고, 일반+고령자가 성인에 대응한다고 보는 근사치다. 주간평균이용인원에 월요일 일반·고령자 비중의 합을 곱한 후 18세 이상 인구로 나눈다. 고유 이용자 기반의 실제 이용률을 뜻하지 않으며 중간지표로만 해석한다. 이 지표와 월요일 유형별 비율은 0~1 단위의 비율(백분율 변환 없음), 고령인구비율·미경험률은 %, 비용은 만원 단위다.

2024년 설명변수와 2026년 이용경험률을 결합한 지역 단위 탐색 분석으로, 인과효과를 추정하지 않는다.

**원자료 불일치**: 유형별 이용인원 합계와 월요일 총이용인원이 16개 시도에서 다르다(유형별 합계−월요일 총계: −1~861명, 강원 861명). 원자료를 보정하지 않고 지정된 계산식대로 유형별 합계를 분모로 사용한다. 01 실행 시 경고와 검증표를 남긴다.

## PCA·지수 정의

PCA 적재값은 변수와 주성분 점수의 상관계수로 정의하고, 고유벡터계수도 별도 열로 저장한다. 설명분산비율은 각 주성분의 변수 행에 반복 기록된다. 전체 4변수 PCA는 요인 검증용으로 유지한다.

| 지수 | 정의 |
| --- | --- |
| 인프라차량종합지수 | 주간평균배차간격·1인당자가용등록대수·1일평균주행거리를 각각 표준화한 뒤 구한 PC1 점수 |
| 고령화지수 | 고령인구비율의 z점수, 참고용 보관(회귀·유형화 제외) |

종합지수는 배차간격의 가중치가 양수가 되도록 부호를 고정한다. 현재 가중치는 배차간격 0.565407, 등록대수 0.562606, 주행거리 0.603150이며 PC1 설명분산비율은 67.1484%다. 세 변수에서는 PCA와 동일 가중 z평균이 일반적으로 같지 않으며, 현재 순위도 다르다. 회귀에는 z평균 대신 PC1 점수를 사용한다. 이전 분리 지수 열은 저장하지 않으며, 지수 재정의에 따라 03~06 산출물을 모두 다시 생성해야 한다. 전체 4변수 PCA는 고령화까지 포함한 참고용으로만 유지하며 회귀 입력을 결정하지 않는다.

## 회귀 모형

| 모형 | 구성 |
| --- | --- |
| 모형1 | 인프라차량종합지수만 사용 |
| 모형2 | 모형1 + 성인대중교통이용률(z) |
| 모형3 | 모형1 + 월평균대중교통비(z) |

종속변수는 미경험률이다. 고령화지수는 모든 회귀 모형에서 제외한다. 표본이 17개뿐이므로 절편 제외 설명변수 4개 이하 제한은 유지하며, 현재 모형1은 1개, 모형2·3은 2개다. p값은 일반 OLS의 양측 검정으로, PCA 지수 추정과 모형 선택의 불확실성까지 반영하지 않는다. 유의성만으로 모형의 우열이나 인과효과를 판단하지 않는다.

## 05 강건성 검증 조건

전체 17개, 수도권 제외 14개, 서울 제외 16개, 평일 배차간격으로 교체 17개, 기준 모형의 최대 절댓값 잔차 지역 제외 16개의 5개 조건을 비교한다. 마지막 조건은 다른 제외 조건에 누적하지 않고 전체 17개에서 해당 1곳만 제외한다. 지역 제외 조건에서는 전체 표본에서 계산한 종합지수를 고정한다. 따라서 이는 고정 지수에 대한 회귀 민감도 검증이며 PCA 가중치의 표본 안정성 검증은 아니다. 평일 조건에서는 배차간격을 평일 값으로 바꾼 후 전체 17개에서 세 변수 표준화와 PCA를 다시 적합한다. 표준화계수는 각 분석 표본의 X·Y 표준편차로 계산한다. 유의성은 양측 OLS p<0.05이며 표에 p값으로 기록한다. 01에는 이미 평일평균배차간격이 있어 01·02 코드는 변경하지 않는다.

## 06 지역 유형화 규칙

05 기준 모형에서 종합지수의 p<0.05 여부를 자동 확인한다. 현재 데이터로 재적합해 05 결과와 일치하는지도 검증한다. 종합지수의 z와 선택 여부를 저장한다. 고령화나 개별 구성변수는 별도 판정 축으로 사용하지 않는다.

| 조건 | 판정 |
| --- | --- |
| 종합지수 유의, z ≤ 0 | 양호형 |
| 종합지수 유의, z > 0 | 인프라·차량의존 취약형 |
| 종합지수 비유의 | 판정유보 |

높은 z를 취약 방향으로 보는 규칙을 사용하며, 계수의 부호에 따라 축을 반전하지 않는다.

유형화에서만 PC1 점수를 z표준화하며 회귀에는 원래 PC1 점수를 사용한다. 산점도는 단일 축 도표로 가로축만 분석 요인이고 세로축은 라벨 겹침을 피하는 지역 표시 위치다. z=0 수직선만 표시하며 2×2 유형화는 하지 않는다. 이 분류는 탐색적 상대 분류이며 개별 지역의 인프라 부족과 차량 의존을 분리해서 진단하지 못한다.

## 실행 검증 결과

고정된 패키지 버전과 Python 3.12.7 환경에서 수정·신규 03~06 모두 종료 코드 0으로 완료했다. Python 3.11 직접 실행은 미검증이다.

- 지수 데이터는 17행·19열이며 결측이 없다.
- 종합지수만 사용한 모형1의 p-value는 0.000122617, 계수는 +5.285165이며 이전 개별 계산 결과와 일치한다.
- 모형1~3의 R²는 각각 0.6372, 0.6425, 0.6571이다. 종합지수의 p-value는 각각 0.000122617, 0.277509, 0.000280987이다. 성인대중교통이용률을 추가한 모형2에서는 종합지수가 유의하지 않다.
- 강건성 5조건의 R²는 순서대로 0.6372, 0.7314, 0.7420, 0.6384, 0.6638이며, 최대 절댓값 잔차 지역은 경기도다. 해당 5조건에서는 기준 대비 부호·유의성 변화가 없었다. 이는 추가 변수를 넣은 모형2의 결과와 구분해야 한다.
- 표본 17개로 인해 OLS 요약의 첨도 기반 정규성 검정은 n<20 경고가 발생한다.
- 지역 유형은 양호형 8개, 인프라·차량의존 취약형 9개다. 01·02와 원자료는 변경하지 않았으며 Git 스테이징·커밋·푸시는 실행하지 않았다.
